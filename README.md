## IF you also want to use this code then follow the following steps:
1) install Compposer `https://getcomposer.org/` and Laravel `https://laravel.com/` from google.
2) Start your XAMPP server.
3) Run the migrations in the terminal after opening the folder on your local machine.
4) Run `php artisan serve` command
